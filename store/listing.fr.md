# Fiche boutique — Pare-Facho (français)

## Nom
Pare-Facho

## Résumé (Chrome : 132 caractères max)
On bloque l'extrême droite : masque les publications des comptes d'extrême droite listés, que vous les suiviez ou non.

## Description longue

Pare-Facho masque sur X les publications des comptes d'extrême droite, à partir de listes que vous choisissez. Elle ne touche pas à votre compte : aucun blocage, aucun signalement, rien n'est envoyé à X.

Ce que fait l'extension :

• Masquer. Les publications des comptes listés disparaissent de votre fil, des réponses, de la recherche et des profils dès qu'elles s'affichent. Les republications faites par un compte listé sont masquées aussi. Rien ne change sur X, seulement votre écran.

• Un bouton ⛔ sur chaque publication : un clic pour masquer et ajouter le compte à votre liste. Cinq secondes pour annuler.

• Vos listes, votre contrôle. La liste du site « On bloque l'extrême droite » est abonnée d'office et mise à jour automatiquement ; vous pouvez la retirer, vous abonner à d'autres adresses, ajouter vos propres comptes, et « garder » n'importe quel compte pour qu'il ne soit jamais masqué.

• Page de réglages : comptes masqués, listes abonnées, liste complète avec recherche, journal.

Vie privée : aucune donnée collectée, aucun serveur. Tout reste dans votre navigateur. Les seules connexions sont le téléchargement des listes (celle fournie par défaut et celles que vous ajoutez).

À savoir : le masquage ne vaut que dans ce navigateur ; l'application mobile affiche tout. Quand X change son affichage, l'extension peut cesser de masquer jusqu'à une mise à jour.

Logiciel libre (GPL-3.0). Code source : https://github.com/pare-facho/blocklist-extension

## Objectif unique (Chrome « single purpose »)
Masquer sur X les publications des comptes figurant dans des listes choisies par l'utilisateur.

## Justification des permissions (Chrome)
- storage : enregistrer les listes, les réglages et le journal, localement.
- alarms : retélécharger les listes périodiquement.
- Accès au site x.com (host permission) : masquer dans la page les publications des comptes listés et afficher le bouton ⛔. Aucune requête n'est envoyée à X.
- Accès au site pare-facho.github.io (host permission) : télécharger la liste fournie par défaut et ses mises à jour.
- Accès optionnel à d'autres sites (optional host permission https://*/*) : demandé uniquement, et au cas par cas, quand l'utilisateur ajoute l'adresse d'une liste, pour pouvoir la télécharger.
- Aucun code distant : tout le code est dans le paquet.
